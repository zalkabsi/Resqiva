# Resqiva demo narration

Target runtime: about 2 minutes 20 seconds. Keep the recording under 3 minutes.

## Script

**0:00–0:18 — Introduction**  
Surplus groceries can be a good deal, but shoppers still need to know what they can make, what it will cost, and when they can pick it up. Resqiva turns store inventory into meal options that fit a shopper’s request.

**0:18–0:35 — Demo context**  
This is the live Resqiva demo. The stores and inventory are fictional sample data. I’ll use the Corner Harvest store to plan a vegetarian dinner for two, under twenty-five dollars, with no peanuts, for pickup tomorrow.

**0:35–1:05 — Shopper flow**  
Resqiva returns three meal options based on the selected store’s inventory. Each option shows its ingredients, price, and pickup window, so shoppers can compare plans that fit their budget. The planner checks the request against available stock and the data stored for each item.

**1:05–1:32 — How it works**  
The project includes a Fireworks AI integration for turning natural-language requests into structured preferences. To keep this hosted demo free and key-free, it currently uses a deterministic local parser. The optimizer applies the inventory and budget rules on the server. Unknown allergen information stays unknown; the demo does not certify food as allergy-safe.

**1:32–1:58 — Merchant flow**  
The merchant workspace provides inventory and order views, with tools for editing stock and prices, importing a CSV, and managing demo stores and pickup windows. These controls use the same fictional demo catalog.

**1:58–2:20 — Payment status and close**  
Resqiva also includes a PayPal Sandbox integration for checkout and payment reconciliation. Sandbox authentication is currently failing, so buyer approval and payment capture have not been verified. This demo does not show a completed payment. Resqiva is a working prototype, and all stores and inventory shown here are sample data.
